# 14 · Content Room

Shared chat for the people who plan and make content. Not a seat. No Dreamstate login of its own.

## Members

- Graphic Designer
- YouTube Writer
- X Writer
- LinkedIn Writer
- Head of Content
- Chief of Staff

## How the room behaves

The Head of Content posts the assignment as a pointer: channel, angle, file path or social draft id, and deadline. The writer or the designer answers with the path of the draft. The Chief of Staff answers with the branch when a coding agent produced it.

Messages stay short. The draft lives in the local workspace repo or in a Dreamstate social draft. The room does not publish, schedule, enroll, or spend. Publishing still needs an approval that names the draft, from the seat that owns the channel.

Create the room in Grok Bot and include every name above. The setup prompt does this when you run it. Add no further member unless the owner edits this file first.

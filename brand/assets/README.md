# Assets

This folder ships with no logos, photos, or icons. Owner-supplied files go in `brand.local/assets/`. List each one in `brand.local/assets/README.md`.

A photo of a person is allowed only when the owner supplied that file. Do not generate, retouch, or replace a face or a body. Do not draw a face to stand in for a missing photo.

If a design needs a logo, a photo, or an icon that this list does not name, stop and ask the owner. Do not download a stand-in.
